## 🛠 Quick Start Guide

### Prerequisites
- Node.js (v18+)

### Easiest Way to Run (One-Click)
- **Windows**: Double-click **`run.bat`** in the root gallery folder (or in `birthday-surprise/`).
- **PowerShell / Terminal**:
  ```bash
  npm start
  ```
  *(or `npm run dev`)*
  This automatically boots both the Backend (Port 5000) and Frontend (Port 5173), and pops open your browser directly to `http://localhost:5173`!

### Manual Start Options
- **Frontend only**:
  ```bash
  cd birthday-surprise/frontend
  npm run dev
  ```
- **Backend**:
  ```bash
  cd birthday-surprise/backend
  npm run dev
  ```
